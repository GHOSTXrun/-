# NOXVIL Native Terminal

独立、原生可操作的终端原型。按参考视频制作界面，不依赖原 Cellumo 模板，不含 iframe、缩放嵌入或 parent 消息通信。

## 启动

双击同目录「打开独立终端.html」。推荐 Node.js 20+ 本地服务，避免浏览器跨域限制：

    npm start

打开 http://127.0.0.1:4310 。无第三方依赖、API 密钥和钱包要求。

## 数据与模型

- DEX Screener Solana 最近收录资料 + SOL 观察列表；默认每 15 秒抓取聚合价格、流动性、成交量和成交笔数。
- 资料收录时间不代表代币刚发行；价格抓取时间不代表链上可执行报价时间。
- 六个角色是明确的规则阶段，不是训练好的 AI 或 LLM。
- Guard 仅检查价格抓取时效、流动性、小时成交量和近期卖出笔数。蜜罐、铸币/冻结权限、真实卖出模拟未接入，因此标注 LIMITED。
- 模拟开仓按可用现金分配仓位，费用每侧 0.1%，冲击成本使用常数乘积储备近似；这不是路由器报价。
- 已开仓持有真实后续价格变化；止盈、止损、持仓超时和会话亏损限制在新鲜行情到达时判断。暂停策略停止自动纸面下单，市场观察继续。
- 手动纸面买入/平仓、观察列表、参数设置、代理与追踪号筛选、JSON 和 CSV 导出均可操作。
- 会话保存于本浏览器，刷新后策略暂停；关闭浏览器不继续运行。资金曲线展示最近 600 次市场观察。

没有合成行情、自动增长余额或伪造交易记录。初始 $33.40 是可设置的纸面资金，未连接真实钱包。

## 已知连接限制

交付环境实际访问行情源失败（浏览器 Failed to fetch，本地代理 fetch failed）。程序已处理此情况：明确显示 DATA OFFLINE，保留上次数据的状态，拒绝新的纸面开仓。接口是否可用取决于运行环境的网络和上游服务。

模型与浏览器功能使用隔离的 API 契约测试数据验收。测试数据仅存在于测试浏览器配置中，不打包进交付页面。
